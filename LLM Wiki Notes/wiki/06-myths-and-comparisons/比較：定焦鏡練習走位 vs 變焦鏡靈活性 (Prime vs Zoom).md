# 比較：定焦鏡練習走位 vs 變焦鏡靈活性 (Prime vs Zoom)

## 一句話核心抉擇
「新手該先買定焦還是變焦？」是攝影界永恆的爭論：**定焦鏡以「極限大光圈、輕巧與強迫走位」培養最嚴謹的攝影眼；而變焦鏡則以「原地多焦段應變與構圖彈性」保障在多變環境中不錯過精彩瞬間。**

---

## 核心權衡維度比較表

| 決策維度 | 定焦鏡頭 (Prime Lens，如 35mm f/1.8, 50mm f/1.8) | 標準變焦鏡頭 (Zoom Lens，如 24-70mm f/2.8 或 18-55mm) |
| :--- | :--- | :--- |
| **光圈與進光量** | **f/1.4 ~ f/1.8 超大光圈**（進光量是 f/2.8 的 2 到 4 倍） | 通常為 **f/2.8**（昂貴的大三元）或 **f/3.5-5.6**（入門浮動光圈） |
| **散景虛化能力** | **極致純淨的奶油虛化**，主體瞬間與背景剝離 | 散景虛化較平緩，雜亂背景難以徹底抹平 |
| **夜間弱光手持** | 極強，能壓低 ISO 保證快門，室內微光依然從容 | 弱光下必須依賴高 ISO 或極限防手震才能維持快門 |
| **構圖學習心態** | **強迫身體走動**；必須靠近、後退、趴下尋找角度，極度磨練透視感 | 容易站在原地懶惰轉動變焦環，視角單一平庸 |
| **不可替代場景** | 人像寫真、咖啡廳室內美食、夜間街頭隨拍、低預算發燒友 | **不可走動的場景**（隔著圍欄、懸崖、運動賽事觀眾席、婚禮抓拍） |
| **體積與重量負擔** | 輕巧隨身，如同一顆蘋果，讓人願意天天帶出門 | 粗壯沉重，常讓人產生「今天好累不想背相機」的心理障礙 |

## 新手選鏡四步決策樹 (Decision Tree)

```text
你主要的拍攝題材是什麼？
  ├── A. 人像寫真、日常美食咖啡廳、追求漂亮背景模糊、預算緊湊 (5000~15000台幣)
  │      └──► 【果斷選擇：35mm 或 50mm f/1.8 大光圈定焦鏡】
  │
  ├── B. 旅遊風景、家庭活動聚會、商業活動紀錄、無法隨意走位抓拍
  │      └──► 【果斷選擇：標準變焦鏡 (如 24-70mm 或 18-50mm)】
  │
  └── C. 完全迷茫、不知道自己喜歡拍什麼的新手
         └──► 【起手式：先用相機隨附的 Kit 套裝變焦鏡拍 3 個月】
                 │
                 ▼ 檢驗 Lightroom 數據：看自己哪一個焦距拍最多，直奔該焦段的 f/1.8 定焦鏡！
```
